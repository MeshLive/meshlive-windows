# Developer documentation

For people who build, test or change MeshLive for Windows. The user documents and the overview are in the
[README](../../README.md).

- [Contributing](../../CONTRIBUTING.md): how to report a bug or a PC result and send a change.
- [Building](building.md): build, test and package from source.
- [Architecture](architecture.md): how the app is built: modules, Bluetooth roles, calls, streams, video, storage.
- [Switches](switches.md): the register of experimental, alternative and optional switches.
- [Testing](testing.md): unit tests, checks with your own phone, developer probes and the acceptance gates.
- [Video encoding](video-encoding.md): encoder order, hardware and software encoders, measurements.
- [Design: watch and go live](design/watch-and-go-live.md): how a PC joins Android live streams (design record).
- [Store certification notes](../../packaging/CERTIFICATION.md): package capabilities and the reviewer path.
- [Protocol](https://github.com/MeshLive/meshlive-android/blob/main/docs/dev/protocol/README.md): wire formats and
  security rules, shared by every MeshLive app and owned by meshlive-android.
- [Security](../../SECURITY.md): report a vulnerability privately.
- [Code of conduct](../../CODE_OF_CONDUCT.md): how we treat each other.
